# The Huxley — Soluções 💻

Repositório destinado ao armazenamento das soluções dos problemas de programação
que resolvi na plataforma [The Huxley](https://thehuxley.com/).

## Sobre o The Huxley 📚

The Huxley é uma plataforma utilizada para prática
de programação por meio da resolução de problemas. Os exercícios apresentam
um enunciado, formato de entrada, formato de saída e casos de teste, e as
soluções submetidas são avaliadas automaticamente.✅


## Organização 📂

Cada arquivo contém a solução de um problema específico da plataforma.

Os problemas podem ser acessados diretamente pela URL:

```
https://www.thehuxley.com/problem/ID
```

### Exemplo

Se o ID do problema for `3337`, o link para o enunciado será:

[Problema 3337](https://www.thehuxley.com/problem/3337)
